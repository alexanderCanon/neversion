# Bitácoras de Implementación

> [!NOTE]
> **Registro Histórico:** Los documentos contenidos en este directorio representan bitácoras históricas inmutables del proceso de construcción inicial (abril–mayo 2026), incluyendo las migraciones de base de datos (`V1` a `V21`), endpoints originales de Spring Boot y el scaffolding inicial. Sirven como trazabilidad evolutiva de Neversion.

---


## Guía de Uso

Los documentos en esta carpeta son iterativos. Cada agente tiene la responsabilidad de actualizar su bitácora correspondiente al finalizar una tarea o hito importante.

### Bitácoras por Proyecto

- **[Backend Construction](./backend-construction.md)**: Registro de lógica de negocio, API y base de datos.
- **[Panel Construction](./panel-construction.md)**: Registro del desarrollo del panel administrativo (Angular).
- **[Store Construction](./store-construction.md)**: Registro del desarrollo de la tienda y panel del cliente (Angular).

---

## Estructura de Registro Sugerida

Cada entrada en la bitácora debe seguir este formato:

| Fecha | Épica / Tarea | Cambio Realizado | Observaciones |
| :--- | :--- | :--- | :--- |
| YYYY-MM-DD | EPIC-XX | Breve descripción del cambio | Notas técnicas o bloqueadores |
